# Mobile QA checklist

Run this on a 375px-wide viewport before every alpha release.

1. Sign in and complete the first dashboard load.
2. Open Plan, Audit, Execute, Track, and Settings from the bottom navigation; each target must remain usable without horizontal scrolling.
3. Complete a Life Event and verify the success message and refreshed Execute list.
4. In Track, create one net-worth check-in, goal bucket, investment check-in, and cash-flow event.
5. Confirm every form shows loading, validation, and error states; buttons must remain at least 44px high.
6. Generate a CPA report and verify the PDF opens.
7. Test a partner invitation with a separate account once available.

Record browser, viewport, route, expected result, actual result, and a screenshot for every failure.
